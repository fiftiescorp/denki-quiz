# 現場巡回チェック野帳

電気設備の巡回点検を、2人で同じ記録に書き込めるアプリ。判定・所見・測定値・写真をその場で残し、提出用のレポートに書き出せます。

## 使い方

1. Artifact を開き、右上の共有メニューからもう1人を**編集者**として招待する（相手も Claude アカウントが必要）
2. 初回に自分の氏名を登録する（判定と写真の記録者として残ります）
3. 現場名をタップして所在地・発注者を登録する
4. 点検項目ごとに **良／注意／不良／対象外** を選び、必要なら所見・測定値・写真を追加する
5. 点検を終えたら「巡回を確定」→ 記録が履歴に移り、新しい野帳が始まる
6. 「書き出し」から HTML レポート（写真つき）または CSV を保存する

閲覧のみの権限で開いた場合は編集操作が無効になり、その旨が画面に表示されます。

## 共有のしくみ

このアプリは Artifact の `artifact` capability を使い、**ページ自身が新しいバージョンを発行する**ことで記録を共有します。

- 判定のタップや写真の追加をすると、少し待って自動的に共有へ保存されます
- 保存が走ると、開いている全員の画面が最新版に切り替わります
- そのため**文字入力中は保存を待ちます**（入力途中で画面が切り替わらないように）。入力欄から離れるか「今すぐ保存」で保存されます
- 相手の保存が先に届いた場合（`conflict`）は、その最新版に切り替わります。書きかけの所見は `sessionStorage` に退避してあり、切り替え後に復元されます

リアルタイムの同時カーソル編集ではなく、**同じ帳票を交互に書き込む**モデルです。2人で別々の項目を担当する巡回に向いています。

## 写真の扱い

外部ストレージを使わず、**写真は記録そのものに JPEG として埋め込まれます**。

- 取り込み時に長辺 1400px / 品質 0.62 まで圧縮（大きい場合はさらに再圧縮）
- 記録全体の上限は 11 MB。画面下の容量計で残りが確認できます
- 上限に達すると写真の追加が止まります。不要な履歴や写真を削除すると空きが戻ります

## 点検項目

受変電設備 / 分電盤・制御盤 / 照明・コンセント / 動力設備 / 配線・接地 / 安全管理 の6分類・23項目を初期搭載。分類ごとに項目を追加できます。絶縁抵抗・接地抵抗・油温などの項目には測定値の入力欄が付きます。

## このファイルについて

`artifact.html` は **Artifact 用のソース断片**です。`<html>` / `<head>` / `<body>` を持たず、公開時にスキャフォールドで包まれます。そのままブラウザで開いても動きません。ローカルで確認する場合は doctype と `<html><head></head><body>` で包んでください。

公開・更新は Claude Code の Artifact ツールから同じファイルパスで再公開します（URL は変わりません）。
