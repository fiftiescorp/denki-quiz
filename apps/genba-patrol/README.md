# 物件巡回野帳

木造・軽量鉄骨の小規模アパートや戸建てを、オーナー自身が見て回るための巡回記録アプリ。2人で同じ記録に書き込めます。

## 設計の前提

管理会社ではなく**オーナーが自分の足で回る**ことを前提にしています。したがって、

- 点検項目は**巡回で実際に目視する箇所だけ**（アパート15項目・戸建て10項目）
- 判定は **異常なし／要観察／要修繕／該当なし** の4つだけ。測定値の入力欄は持たない
- **異常がない項目には何も書かせない**。所見・写真・対応状況の欄は、要観察か要修繕にしたときだけ開く
- ひと回りして問題がなければ「**残りを異常なしに**」の1タップで巡回が終わる
- 未対応の指摘は**次回へ自動で持ち越す**。オーナーの頭の中の申し送りをアプリが持つ

## マスター構造

後から表計算で集計する前提で、以下の構造を持ちます。CSVの書き出しはこの構造に沿った明細です。

| マスター | 主なフィールド |
|---|---|
| **物件** | 物件ID / 物件名 / 種別（アパート・戸建て）/ 所在地 / 戸数 / 建築年 / メモ / 物件固有の追加項目 |
| **点検項目** | 項目ID / 分類 / 項目名 / 対象種別 / 記入のヒント |
| **巡回** | 巡回ID / 物件ID / 巡回日 / 天候 |
| **点検明細** | 巡回ID / 項目ID / 判定 / 対応状況 / 所見 / 写真[] / 持ち越し / 記録者 / 記録日時 |
| **更新ログ** | 日時 / 記録者 / 操作内容 |

種別は「アパート・共同住宅」と「戸建て」の2つ。戸建てでは共用部の4項目（共用廊下・階段／共用照明／ゴミ置場／郵便受け）が出ません。

| 分類 | 項目 | 戸建て |

| | 郵便受け・宅配ボックス | — |
| 設備 | 給湯器まわり（外観・排気） | ○ |

## 使い方

1. Artifact を開き、右上の共有メニューからもう1人を**編集者**として招待する（相手も Claude アカウントが必要）
2. 自分の氏名を登録する（判定・写真・更新ログの記録者として残ります）
3. 「物件」から巡回する建物を登録する
4. ひと回りしながら、気になった箇所だけ **△要観察** か **✕要修繕** にして、所見と写真を残す
5. 最後に「**残りを異常なしに**」を押す
6. 「**巡回を確定**」で今回分が履歴に移り、未対応の指摘だけが次回の申し送りとして残る
7. 「書き出し」から HTML レポート（写真つき）または CSV を保存する

対応が済んだ指摘は、その項目の「対応」を **完了** にすると次回から持ち越されなくなります。

## 更新日時の見えかた

| 場所 | 内容 |
|---|---|
| 巡回票の「前回巡回」 | 前回の巡回日と経過日数 |
| 各項目の右肩 | その項目の前回判定と日付（例：前回 ✕ 8/27） |
| 指摘の下段 | 記録者・記録日時・写真枚数 |
| 写真 | 取り込み時刻（サムネイル）／撮影者とひとことメモ（拡大時） |
| 巡回票の下段 | 直近の更新1件 |
| 履歴 →「更新ログ」タブ | 誰がいつ何を変えたか（最新60件） |

## 共有のしくみ

Artifact の `artifact` capability を使い、**ページ自身が新しいバージョンを発行する**ことで記録を共有します。

- 判定のタップや写真の追加をすると、少し待って自動的に共有へ保存されます
- 保存が走ると、開いている全員の画面が最新版に切り替わります
- そのため**文字入力中は保存を待ちます**。入力欄から離れるか「今すぐ保存」で保存されます
- 相手の保存が先に届いた場合（`conflict`）はその最新版に切り替わります。書きかけの所見は `sessionStorage` に退避してあり、切り替え後に復元されます

リアルタイムの同時カーソル編集ではなく、**同じ帳票を交互に書き込む**モデルです。2人で棟を分担する巡回に向いています。書き込み権限のない閲覧者には自動で閲覧専用の画面になります。

## 写真

外部ストレージを使わず、**写真は記録そのものに JPEG として埋め込まれます**。

- 「写真」ボタンから**複数枚まとめて**選べます（カメラ起動にも対応）
- 取り込み時に長辺 1280px / 品質 0.6 まで圧縮（大きい場合はさらに再圧縮）。1枚あたりおよそ 30〜200KB
- 拡大表示で前後に送れ、ひとことメモ（例：北面2階サッシ下）を付けられます
- 記録全体の上限は 11MB。画面下の容量計で残りが確認できます
- 容量が苦しくなったら、履歴の各巡回にある「**写真だけ削除**」で判定と所見を残したまま空けられます。先にレポートを書き出しておけば写真は手元に残ります
- 巡回を確定しても写真は次回へ引き継がれません（同じ箇所を撮り直す想定＋容量対策）。過去の写真は履歴に残ります

## 表計算での集計

CSV は 1行＝1点検項目です。複数物件・複数回分を1枚のシートに積み上げると、そのまま集計できます。

```
=SUMIFS(集計!A:A, 集計!判定, "要修繕", 集計!物件名, $A2)          物件別の要修繕件数
=QUERY(集計!A:N, "select G,J,N where H='要修繕' and I<>'完了' order by D desc", 1)
                                                                  未完了の指摘一覧
=COUNTIFS(集計!物件名, $A2, 集計!持ち越し, "持ち越し")            繰り越している件数
```

判定・対応状況を文字列で持たせているのは、この手の関数で直接条件に書けるようにするためです。

## このファイルについて

`artifact.html` は **Artifact 用のソース断片**です。`<html>` / `<head>` / `<body>` を持たず、公開時にスキャフォールドで包まれます。そのままブラウザで開いても動きません。ローカルで確認する場合は doctype と `<html><head></head><body>` で包んでください。

公開・更新は Claude Code の Artifact ツールから同じファイルパスで再公開します（URL は変わりません）。**再公開するとページ本体だけでなく埋め込みの記録も置き換わる**ため、実際に使い始めたあとで更新するときは、先にレポートを書き出して控えを取ってください。
